# Экипировка и дроп

Документ фиксирует принятый каркас постоянной экипировки. Числовые диапазоны аффиксов, названия баз и итоговые веса будут уточняться отдельно, но перечисленные ниже правила считаются базовыми ограничениями системы.

## Слоты и класс

В первом срезе доступен один класс — лучник — и шесть слотов экипировки:

1. лук;
2. колчан;
3. шлем;
4. броня;
5. перчатки;
6. штаны.

Лук отвечает за базовый урон, скорость атаки и базовый шанс критического удара. Колчан усиливает атаку и свойства стрел. Четыре защитных слота являются источниками брони и могут получать допустимые для своего слота защитные или вспомогательные аффиксы.

## Редкость и количество аффиксов

Предметы используют PoE-подобное разделение на базу, префиксы и суффиксы.

| Редкость | Аффиксы | Ограничение                        |
| -------- | ------: | ---------------------------------- |
| Белая    |       0 | Только характеристики базы         |
| Синяя    |     1–2 | Не более 1 префикса и 1 суффикса   |
| Жёлтая   |     3–4 | Не более 2 префиксов и 2 суффиксов |

Жёлтый предмет не обязан иметь четыре свойства. Допустимы распределения `2 префикса + 1 суффикс`, `1 + 2` и `2 + 2`.

Для первого игрового среза установлены легко заменяемые стартовые веса редкости: 60% белых, 30% синих и 10% жёлтых предметов. Это техническая отправная точка для тестирования интерфейса, а не окончательное решение баланса.

## Получение и хранение

- За победу выдаются ровно три предмета уровня пройденной арены.
- При поражении предметы не выдаются.
- Награды автоматически добавляются в постоянный инвентарь.
- На экране победы предмет можно сразу надеть или оставить в инвентаре.
- Повторное прохождение арены снова выдаёт полный набор наград.
- Страж начинает со стартовым белым коротким луком I ранга `13–19`, `1,55 атаки/с`, `5%` базового критического шанса.
- Без лука Страж не должен начинать бой; в текущем сохранении стартовый лук всегда создан и надет.

## Уровень предмета

- В игре 100 уровней арен и 100 уровней предметов.
- На каждой арене одна волна.
- Уровень выпавшего предмета всегда равен уровню арены.
- Уровень предмета определяет доступные ранги баз и аффиксы, но не гарантирует сильный результат.
- Высокоуровневый предмет может получить любой слабый тир аффикса, который уже был открыт.

Пример: на Арене 37 выпадают предметы 37-го уровня. Они не могут получить базу или аффикс, требующие 41-й уровень, но могут получить слабый аффикс, открытый на первом уровне.

## Ранги баз

У каждой линии баз десять рангов. Новый ранг открывается каждые десять уровней.

| Ранг | Уровни предметов |
| ---: | ---------------: |
|    I |             1–10 |
|   II |            11–20 |
|  III |            21–30 |
|   IV |            31–40 |
|    V |            41–50 |
|   VI |            51–60 |
|  VII |            61–70 |
| VIII |            71–80 |
|   IX |            81–90 |
|    X |           91–100 |

После открытия нового ранга распределение баз фиксировано:

- база текущего ранга — 15%;
- база предыдущего ранга — 85%;
- более старые базы не выпадают;
- на уровнях 1–10 база I ранга выпадает со 100% вероятностью.

Таким образом, база нового ранга является самостоятельной редкой наградой. После открытия следующего ранга бывшая редкая база становится основным дропом.

## Архетипы баз

Слот определяет допустимый пул аффиксов. Конкретная база внутри слота влияет только на собственные базовые характеристики и не запрещает аффиксы из общего пула слота.

Для луков сохраняются три линии баз:

- быстрый лук — меньший урон и высокая базовая скорость атаки;
- мощный лук — высокий урон и низкая базовая скорость атаки;
- критический лук — средние урон и скорость, повышенный базовый шанс критического удара.

Для колчанов сохраняются три направления базы: урон, скорость атаки и критический удар.

После удаления уклонения защитным слотам не нужны ложные архетипы «тяжёлая / лёгкая / гибридная». Для шлема, брони, перчаток и штанов используется по одной основной линии базы каждого ранга. Разнообразие создают ранг, базовое значение брони, редкость и аффиксы.

## Броня

- Врождённая броня Стража — 0%.
- Барьера и уклонения нет.
- Броня приходит только с экипировки.
- Значения брони со всех предметов складываются.
- Один процентный пункт брони снижает входящий физический урон на один процент.
- Максимальное фактическое снижение физического урона от брони — 75%.
- Значение выше 75% сохраняется для возможного будущего взаимодействия с пробиванием брони.

Формула урона:

```text
effectiveArmor = min(totalArmor, 75%)
receivedPhysicalDamage = rawPhysicalDamage * (1 - effectiveArmor)
```

Целевая броня полного белого комплекта текущего ранга:

| Ранг | Полный белый комплект |
| ---: | --------------------: |
|    I |                   10% |
|   II |                   14% |
|  III |                   18% |
|   IV |                   22% |
|    V |                   26% |
|   VI |                   30% |
|  VII |                   34% |
| VIII |                   38% |
|   IX |                   42% |
|    X |                   46% |

Ориентировочное распределение базовой брони полного комплекта: броня — 40%, штаны — 30%, шлем — 20%, перчатки — 10%. Точные целочисленные значения отдельных баз определяются таблицами баланса.

## Тиры и уровни аффиксов

Обычные числовые семейства используют до восьми тиров. T1 — сильнейший тир, T8 — слабейший. Только предмет 100-го уровня может получить T1.

| Тир | Минимальный уровень предмета |
| --: | ---------------------------: |
|  T8 |                            1 |
|  T7 |                           11 |
|  T6 |                           21 |
|  T5 |                           36 |
|  T4 |                           51 |
|  T3 |                           66 |
|  T2 |                           81 |
|  T1 |                          100 |

Специализированные аффиксы могут открываться позднее и иметь меньше восьми тиров. Например, дополнительная стрела может существовать только как редкий поздний аффикс.

Для префикса повышения физического урона лука зафиксированы следующие диапазоны:

| Тир | Требуемый уровень | Физический урон |
| --: | ----------------: | --------------: |
|  T8 |                 1 |         +10–19% |
|  T7 |                11 |         +20–29% |
|  T6 |                21 |         +30–39% |
|  T5 |                36 |         +40–49% |
|  T4 |                51 |         +50–59% |
|  T3 |                66 |         +60–69% |
|  T2 |                81 |         +70–79% |
|  T1 |               100 |        +90–100% |

## Веса аффиксов

Аффиксы генерируются по модели, близкой к Path of Exile и Craft of Exile:

- глобальной вероятности тира нет;
- каждое сочетание `семейство аффикса + тир` является отдельной записью с собственным весом;
- в розыгрыше участвуют все записи, доступные уровню предмета и его слоту;
- вероятность записи равна её весу, делённому на сумму весов всего допустимого пула;
- сильные тиры обычно имеют меньший вес, но веса задаются отдельно для каждого семейства;
- после выбора записи остальные тиры того же семейства исключаются, поэтому одинаковый аффикс нельзя получить дважды;
- значение внутри выбранного тира дополнительно бросается из заданного диапазона.

Поздний дроп намеренно должен примерно в 99% случаев быть неидеальным. Это достигается большим общим пулом, несовпадением нужных семейств, слабыми тирами, ограничениями префиксов и суффиксов и случайным значением внутри тира, а не одной глобальной таблицей вероятностей T1–T8.

## Ограничение пулов по слотам

Слот является главным ограничителем пула. Предварительные направления:

| Слот     | Допустимые направления                                                                      |
| -------- | ------------------------------------------------------------------------------------------- |
| Лук      | Физический урон, плоский урон, скорость атаки, критический шанс, критический урон, точность |
| Колчан   | Урон, скорость атаки, критические свойства, точность, свойства стрел                        |
| Шлем     | Здоровье, броня, сопротивления, восстановление и вспомогательная защита                     |
| Броня    | Здоровье, броня, сопротивления, снижение получаемого урона                                  |
| Перчатки | Скорость атаки, точность, критические свойства, небольшой плоский урон, защитные свойства   |
| Штаны    | Здоровье, броня, сопротивления, скорость передвижения                                       |

Конкретная линия базы не сужает этот пул. Например, аффикс скорости атаки может выпасть на мощном луке, а физический урон — на быстром. На броне при этом не могут выпасть критический шанс или скорость атаки, если они не включены в пул соответствующего слота.

## Ещё не зафиксировано

До реализации полноценной генерации нужно отдельно утвердить:

- точные названия и базовые значения всех рангов луков и колчанов;
- точные значения брони по слотам и рангам;
- полный список префиксов и суффиксов каждого слота;
- диапазоны, уровни открытия и веса каждого тира;
- вероятность выпадения белых, синих и жёлтых предметов;
- окончательные правила вместимости, удаления и разбора предметов;
- стихийный урон, сопротивления и специальные свойства стрел.

## Текущий технический срез аффиксов

До утверждения полной таблицы используется небольшой рабочий пул аффиксов. Каждый выпавший аффикс уже сохраняет семейство, тип (префикс или суффикс), тир и числовое значение, показывается в описании предмета и влияет на характеристики Стража. Защитные предметы могут давать здоровье, броню и восстановление здоровья; лук и колчан — урон, скорость атаки и критические свойства; перчатки используют смешанный пул.

Это временный набор для проверки полного игрового цикла. Его числовые значения и веса не считаются окончательным балансом.
