# Прогрессия арен

Этот документ фиксирует первую версию скейлинга арен, врагов и опыта. Баланс считается отправной точкой и должен корректироваться после игровых тестов, но правила и формулы должны оставаться централизованными в `src/content/arenaBalance.ts`.

## Основная модель

- В игре 100 уровней арены.
- Изначально открыта только Арена 1.
- Победа на Арене N открывает Арену N+1, максимум — Арена 100.
- Уже пройденные арены можно запускать повторно для опыта и будущего лута.
- Перед каждым забегом игрок сам выбирает любую открытую арену на главном экране.
- Следующая ещё не открытая арена показывается как закрытая.
- Сейчас на арене используются только обычные враги. Уровень обычного врага равен уровню арены.
- Для будущих типов зарезервировано правило: элита — уровень арены +1, босс — уровень арены +2.
- Ориентир сложности: Страж уровня N должен достаточно уверенно проходить Арену N. Арена N+1 уже должна ощущаться сложнее, а несколько уровней вперёд — быть серьёзным испытанием.

## Количество врагов

Количество врагов растёт от 24 на первой арене до 200 на сотой:

`Enemies(N) = round(24 + 176 × ((N - 1) / 99)^1.2)`

Контрольные точки:

| Арена | Врагов |
| ---: | ---: |
| 1 | 24 |
| 10 | 34 |
| 20 | 48 |
| 30 | 64 |
| 50 | 100 |
| 75 | 148 |
| 100 | 200 |

Рост количества врагов — важная часть сложности. Поздние арены должны уметь задавить недостаточно сильного Стража накопившейся толпой.

## Плотность спавна

Увеличение количества врагов не должно пропорционально растягивать бой. Основная масса волны выпускается примерно за 52 секунды:

`SpawnInterval(N) = min(2.2, 52 / (Enemies(N) - 1))`

Контрольные точки:

| Арена | Интервал спавна |
| ---: | ---: |
| 1 | 2.200 с |
| 10 | 1.576 с |
| 20 | 1.106 с |
| 30 | 0.825 с |
| 50 | 0.525 с |
| 75 | 0.354 с |
| 100 | 0.261 с |

У арены нет лимита времени. Если Страж не успевает убивать противников с нужной скоростью, враги продолжают накапливаться на поле.

## Здоровье врагов

HP масштабируется плавно, но после 30 уровня рост усиливается. Базовое HP врага — 60.

- Арены 1–30: +1.2% HP за уровень арены.
- Арены 31–60: +2.2% HP за уровень арены.
- Арены 61–100: +3% HP за уровень арены.

Рост в каждом следующем диапазоне продолжается от результата предыдущего диапазона, без скачка при переходе границы.

Контрольные точки:

| Арена | HP врага |
| ---: | ---: |
| 1 | 60 |
| 10 | 67 |
| 20 | 75 |
| 30 | 85 |
| 50 | 131 |
| 75 | 254 |
| 100 | 531 |

Арены 1–30 должны балансироваться под текущую постоянную прокачку характеристик Стража. После 30 уровня допускается расчёт на будущий лут, оружие и другие источники силы.

## Урон врагов

Урон растёт медленнее HP, потому что сама плотность толпы уже увеличивает входящий урон. Базовый урон атаки — 8.

- Арены 1–30: +0.8% урона за уровень арены.
- Арены 31–60: +1.2% урона за уровень арены.
- Арены 61–100: +1.5% урона за уровень арены.

Контрольные точки:

| Арена | Урон врага |
| ---: | ---: |
| 1 | 8.0 |
| 10 | 8.6 |
| 20 | 9.3 |
| 30 | 10.1 |
| 50 | 12.8 |
| 75 | 18.0 |
| 100 | 26.2 |

Скорость движения врага, интервал его атак и дистанция остановки с уровнем арены не растут.

## Опыт за арену

Целевой темп — примерно пять успешных прохождений арены своего уровня на один новый уровень Стража.

Сначала рассчитывается целевой сырой опыт всей арены:

`TargetArenaXP(N) = XPToNextLevel(min(N, 99)) / 5`

Затем он равномерно распределяется между всеми врагами:

`XPPerEnemy(N) = max(1, round(TargetArenaXP(N) / Enemies(N)))`

Из-за округления реальная сумма может немного отличаться от ровно 20% стоимости уровня.

Контрольные точки:

| Арена | XP за врага | Сырой XP всей арены |
| ---: | ---: | ---: |
| 1 | 1 | 24 |
| 10 | 37 | 1 258 |
| 20 | 92 | 4 416 |
| 30 | 142 | 9 088 |
| 50 | 229 | 22 900 |
| 75 | 321 | 47 508 |
| 100 | 391 | 78 200 |

Более высокая арена естественно даёт больше опыта, но отдельного бонусного множителя за убийство врага выше уровня Стража нет.

## Штраф опыта за слабых врагов

Если враг ниже уровня Стража, награда уменьшается на 10% за каждый уровень разницы:

`Multiplier = max(0, 1 - 0.1 × (GuardianLevel - EnemyLevel))`

Если враг равного или более высокого уровня, множитель всегда равен 100%.

Пример для Стража 20 уровня:

| Уровень врага | Получаемый XP |
| ---: | ---: |
| 20+ | 100% |
| 19 | 90% |
| 18 | 80% |
| 15 | 50% |
| 11 | 10% |
| 10 и ниже | 0% |

Дробная часть награды переносится между убийствами внутри текущего забега, чтобы маленькие базовые награды тоже корректно подчинялись процентному штрафу.

## Постоянный уровень Стража

Максимальный уровень Стража — 100. Опыт не сбрасывается между успешно завершёнными забегами и поражениями, кроме описанного ниже штрафа смерти.

Кривая уровня остаётся:

`XPToNextLevel(level) = round(100 × level^1.8)`

Суммарно для достижения 100 уровня требуется 14 019 656 XP.

## Поражение и смерть

До 30 уровня включительно поражение не отнимает опыт. Весь опыт за уже убитых в забеге врагов сохраняется.

Начиная с 31 уровня смерть отнимает 10% всего текущего суммарного XP после учёта опыта, заработанного в этом забеге:

`AfterDeathXP = max(XPAtCurrentLevelStart, floor(TotalXP × 0.9))`

Нижняя граница гарантирует, что уже полученный уровень никогда не теряется. Можно потерять весь прогресс внутри текущего уровня, но нельзя откатиться на предыдущий уровень.

Если игрок получил новый уровень во время забега и затем погиб, новый уровень сохраняется: нижней границей становится начало уже достигнутого нового уровня.

## Добровольный выход

Если игрок намеренно выходит из незавершённой арены, весь опыт, заработанный именно в этом забеге, аннулируется. Постоянный XP, с которым игрок вошёл на арену, не меняется. Штраф смерти при добровольном выходе не применяется.

Закрытие вкладки, Mini App или приложения во время незавершённого боя трактуется так же: поскольку прогресс боя не сохраняется до результата, XP текущего забега теряется, а постоянный XP остаётся прежним.

## Сохранение и открытие арен

В локальном сохранении хранятся:

- суммарный постоянный XP Стража;
- максимальная открытая арена;
- нераспределённые очки характеристик;
- вложения в постоянные характеристики;
- количество завершённых забегов.

Победа открывает следующую арену. Поражение не меняет максимальную открытую арену. Повторная победа на старой арене также не перескакивает через закрытые уровни.
